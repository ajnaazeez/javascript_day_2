# Day 2 – JavaScript Practice Tasks

This repository contains my second day JavaScript practice programs.
The purpose of these tasks is to improve problem solving, conditional statements, and decision making using JavaScript.

## Topics Covered

* if / else statements
* else if ladder
* Comparison operators
* Logical thinking
* User input handling

## Programs Included

### 1. Number Guessing Game

A simple game where the computer selects a random number and the user tries to guess it.

Features:

* Generates a random number
* User enters a guess
* Displays whether the guess is:

  * Too high
  * Too low
  * Correct

This helped me understand random numbers and conditions.

---

### 2. Traffic Light Simulator

This program simulates a real traffic signal using conditions.

It displays actions based on the color:

* Red → Stop
* Yellow → Ready / Wait
* Green → Go

This helped me practice decision making using `if-else`.

---

### 3. Weekday Number

This program takes a number (1–7) as input and prints the corresponding day.

Example:
1 → Monday
2 → Tuesday
3 → Wednesday
4 → Thursday
5 → Friday
6 → Saturday
7 → Sunday

It also handles invalid numbers.
